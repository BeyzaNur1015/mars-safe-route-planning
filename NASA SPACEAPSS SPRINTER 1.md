**Sprint 1 Report: Problem Analysis and Planning**

We chose the task about finding routes on the surface of Mars. We focused on analyzing data from Jezero Crater and setting limits based on astronaut safety and vehicle capabilities.

We defined the scope of the project. Our main goals were to work with the given data, understand terrain features and build a system that can suggest travel paths.

We split up the work among the team members. Each person took a role that matched their skills. One person handled data work, another focused on coding and interface design while others worked on documentation and preparation for the presentation.

We picked the data sources. The MOLA topography data from NASA was essential, for our project. We also chose tools that would help us process the data build the simulation and create the user interface.
